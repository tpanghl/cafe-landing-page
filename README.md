# cafe-landing

가상의 카페 "모닝빈"의 간단한 랜딩 페이지입니다.

## 구성
- `index.html`: 페이지 전체(HTML + CSS를 한 파일에 포함)

## 페이지 내용
- 메인 문구와 메뉴 보기 버튼
- 대표 메뉴 4종과 가격
- 카페 소개
- 오시는 길, 영업시간, 문의 연락처

## 사용 방법
`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다. 별도의 설치나 빌드는 필요하지 않습니다.

## 참고
AI 에이전트 수업 실습용으로 만든 예제입니다. 상호, 주소, 전화번호는 모두 가상의 정보입니다.
